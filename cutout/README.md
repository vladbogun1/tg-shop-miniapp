# cutout — вырезка товара из фона

Внутренний сервис для «фото по ссылке» в админке. Бэкенд отправляет найденное фото и получает товар отдельно
(PNG с прозрачным фоном, обрезанный по товару). Затем imgproxy ставит его в квадрат 1600 на #1a1a1a.

- Модель — [BiRefNet_lite, ONNX с изменяемым размером](https://huggingface.co/senty-au/BiRefNet_lite-ONNX-dynamic)
  (MIT). Ревизия и sha256 зафиксированы в `fetch_model.py`, модель скачивается при сборке образа.
- Маска считается на 768 px: на сервере (2 ядра ARM) это ~11 с и ~1,3 ГБ пика. Обычная сборка 1024 требует 7+ ГБ.
  Lite на 1024 в проверке обрезал низ белой клавиатуры, на 768 — нет.
- Цвет края очищается от старого фона (`unmix`), чтобы у товара на белом не было светлой каймы на тёмном.
- Режет по одному (семафор). Остальные запросы ждут, бэкенд ждёт до 45 с.
- `422` — резать нечего (товар не найден или фона вокруг нет): бэкенд делает квадрат по-старому, на цвете края.

```
POST /cutout   тело = картинка (≤ 20 МБ) → 200 image/png | 422 | 400
GET  /health
```

Локально: `docker build -t maxsolch2-cutout:dev cutout && docker run -p 127.0.0.1:8095:8090 maxsolch2-cutout:dev`,
бэкенду — `APP_MEDIA_CUTOUTURL=http://<хост>:8095` (пусто = выключено).
