# Shipment redirect

## Create a shipment redirect

> The method allows you to create a redirect for an existing Nova Post shipment and change its delivery location without creating a new shipment.\
> \
> Using this method, a shipment can be redirected:\
> \- to a branch;\
> \- to a parcel locker;\
> \- to the recipient's address.\
> \
> For the new delivery location, only one addressing method must be used:\
> \- \`recipient.divisionId\` — for delivery to a branch or parcel locker;\
> \- \`recipient.addressParts.street\` together with the other required \`recipient.addressParts\` fields — for address delivery.\
> \
> 🔸Do not provide \`recipient.divisionId\` and \`recipient.addressParts.street\` at the same time. If neither of these fields is provided, the request will fail validation.\
> \
> After a redirect is successfully created, there is no need to create a new shipment. The redirect is applied to the existing shipment.<br>
