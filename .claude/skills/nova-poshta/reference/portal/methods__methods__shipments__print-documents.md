# Print documents

## Print Shipment Documents

> This API method allows you to retrieve a transportation document marking by its number. The generated marking can be printed and attached to the cargo before shipment.\
> Two formats are available - PDF and ZPL.\
> By default, the marking is generated in PDF format if the \`format\` parameter is not provided.\
> The ZPL format is available only for shipments where the first and last mile are handled by Nova Post. These are EU-EU and EU-UA routes.\
> Two formats with a resolution of 203 or 300 dpi are available. If the resolution is not specified, 203 dpi is used by default.<br>
