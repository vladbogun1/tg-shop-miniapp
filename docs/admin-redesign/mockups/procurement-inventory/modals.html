10. Мелкие модалки

CancelBatchModal, VariantPickModal, SupplierModal, FactoryOrderLine и подтверждение «Выровнять партии». Каждая — на телефоне нижней шторкой, на ноуте окном по центру.
Отмена поставки
AОдна строка про последствия
Число затронутых ждущих и броней в предупреждении; фокус на «Назад».
BЦифры плитками + причина в журнал
Те же числа крупно, поле «Причина». Для редкой, но дорогой операции.
Выбор варианта (VariantPickModal)
AСетка размеров с бейджем «в поставке»
grid-cols-3 / 4, нажатие добавляет 1 шт, «Готово» липкая.
BСписок со степпером количества
Количество сразу при выборе; сетка не нужна, когда вариантов 3–5.
Поставщик (SupplierModal)
AНазвание + заметка, Enter добавляет
Почти без изменений, только Enter.
BСначала «Уже есть», потом новый
Защита от дублей: видно существующих.
Заказать из спроса при открытых поставках (FactoryOrderLine)
AОдин Select в первой шторке
Вместо двух окон подряд.
BКарточки-варианты: в поставку / новая
Видны сроки и «новая поставка» как равноправный вариант.
«Выровнять партии» — подтверждение
AОписание + число затронутых
useConfirm с одной фразой.
BЦифры плитками + откат 30 с
Более «весомо», требует поддержки отката в логике (спорно).
