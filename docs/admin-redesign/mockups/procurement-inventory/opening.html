8. Начальная себестоимость

Сейчас: сотни карточек с «Сохранить» у каждой, нет поиска и итога, фильтр «без себестоимости» заставляет список прыгать, «Выровнять партии» без подтверждения.
AТаблица быстрого набора
Поле ₴/шт прямо в строке, Enter сохраняет и идёт ниже, сохранённые тускнеют и опускаются. Липкая шапка, поиск, сортировка по стоимости остатка, итог «осталось заполнить N на X ₴».
BПо брендам + «Одна себестоимость выбранным»
Работа порциями: бренды как чаты (сколько без себестоимости, на какую сумму). Внутри — чекбоксы и массовая панель для однотипных товаров. Медленнее для штучного ввода, быстрее для «все коврики Artisan по 160 ₴».
