7. Поставка с ИИ

Сейчас: три этапа в одном скролле, блок промпта остаётся над результатом, в футере только первая проблема, кнопки строк < 44 px.
AТри шага + свёрнутый ответ + фильтры-чипы
После разбора шаг 1 сжимается в плашку «Ответ принят · 42 строки · изменить», строки фильтруются чипами («Требуют решения» по умолчанию). Действия строки на телефоне — ActionSheet, на ноуте — таблица Документ | Это у нас | Действие и липкий сайдбар.
BОчередь решений: одна спорная строка за раз
Спорных строк обычно 3–10: показываем их по одной (прогресс «3 из 5», «Подтвердить · следующая»). Сопоставленные не показываем, пока их не спросят. Ноут: очередь — карточка — документ.
