# Макеты «Товары» и «Карточки» (к отчёту ../../products-cards.md)

Статичный HTML+CSS, без зависимостей. Старт — `index.html`. Телефон 390 px и десктоп 1440 px (местами планшет 820, большой 1920; широкие кадры уменьшены `transform: scale`).
Скриншоты проверки — `_shots/`. Данные придуманы (мыши, клавиатуры, гривны), тексты взяты из кода.

## Рекомендации по экранам

| Экран | Рекомендую | Почему / что спорно |
|---|---|---|
| `products-list` | **A** (таблица + правка в строке + массовые) | Закрывает главную боль: цена/остаток без мастера, массовые действия. Спорно: на телефоне 2 «пилюли» в строке — плотно; вход-список из B годится как стартовый экран «Товаров» на телефоне (ввести позже, если A окажется тесным). |
| `products-filters` | **A** на ПК, **B** на телефоне | Шторка-форма на телефоне забирает клавиатуру; вход-строки B короче. Спорно: два паттерна вместо одного, зато оба уже есть в проекте (Sheet / Popover). |
| `price-stock-edit` | **A** (мини-шторка / popover) | Предсказуемо, причина списания в той же шторке. B (полноэкранный ввод, ввод в ячейке + тост «Отменить») быстрее, но на ПК конфликтует с кликом по строке. Спорно: нужен PATCH без полного объекта. |
| `product-editor` | **A** (секции + липкая шапка) | Меньше переходов, deep-link `step=` превращается в скролл к секции. B (оглавление-вход, вкладки с превью) красив, но хуже для «поправить 3 поля подряд». Спорно: переводы в редакторе — отдельная работа. |
| `variants-photos` | **A** для вариантов, **B** для фото на телефоне | Строка `название · −/+ · 🗑` — минимум изменений. Обложка + лента удобнее сетки 3×N на телефоне. Спорно: логику DnD не трогаем; лента — другой layout, нужно проверить `rectSortingStrategy`. |
| `specs-form` | **A** | Один проход сверху вниз, плашка «15/18». B (группы-входы) полезен только при десятках полей; спорно, где граница. |
| `product-dialogs` | **A** | Мелкие точечные правки (колонка кнопок, автофокус, Enter) почти без риска. B-плитки причины списания приятны, но 4 причины — не повод. |
| `catalog-pickers` | **A** на телефоне (шторка с «Создать бренд» первой строкой), **B** (две колонки) на ПК | Спорно: уровни-«чаты» медленнее при частом выборе. |
| `cards-list` | **A** (мастер-детали ≥1280) | Идёт по очереди без закрытия панели, J/K работают. B (триаж по уверенности + «Принять все 9») — сильная идея, можно добавить как сортировку/группировку внутри A. Спорно: массовое «принять уверенных» — риск принять ошибку ИИ, нужен «Отменить». |
| `card-review` | **A** (решение сверху) | Дёшево, без смены логики. B (сравнение «было → стало» с решением по полю) — для пакетной проверки; на телефоне «поле за полем» медленнее. |
| `card-completion` | **A** (двухколонная модалка xl) | Малый риск. B (липкий степпер, две колонки на 1920) имеет смысл только в мастере на больших экранах (P3). |
