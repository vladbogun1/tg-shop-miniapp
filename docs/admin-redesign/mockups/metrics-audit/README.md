# Макеты «Метрики» и «Журнал» — варианты A/B

Статичные HTML (без зависимостей), открывать `index.html`. Основа — `docs/admin-redesign/metrics-audit.md`. Данные придуманы. Скриншоты проверки — `_shots/`.
Кадры: телефон 390, планшет 820 (где уместно), десктоп 1440, большой 1920 (Обзор, Маржа).

## Рекомендации

**Шапка** — рекомендую A (липкая полоса + шторка периода): минимум переделок, решает главную боль (прокрутка наверх). Спорно: B (вкладки как список чатов) красивее и ближе к принятому направлению для «Заказов», но добавляет лишний тап на каждый переход между вкладками.

**Сегодня** — A (две группы). Простая сетка без `min-w`, «действия» отделены от «цифр». Спорно: B с графиком по часам требует почасовых данных, которых в плитке сейчас нет.

**Обзор** — A. Тот же состав блоков в порядке важности, главный график сразу после KPI. Спорно: B (герой + разделы-входы) хорош на телефоне, но прячет деньги в пути и онлайн-оплату за тап; можно взять его только для телефона.

**Склад** — A на десктопе, B-вход на телефоне. «Что дозаказать» первым — главное; список-входов по проблемам на телефоне ближе к принятому образцу. Спорно: три колонки B на 1440 тесные для длинных названий.

**Покупатели** — A. Матрица с числом внутри понятна и закрывает контраст. Спорно: B (кривая возврата) проще, но теряет разрез по когортам; взять как верхний блок над матрицей.

**Воронка** — A. Бары проще адаптировать и они не искажают малые шаги. Спорно: трапеции B выразительнее, но шаги с долей < 5 % превращаются в полоску, а ширина по корню нечестна.

**Операции** — A: срочное наверх с кликом в заказ. Спорно: единая очередь B удобна для «разобрать всё», но смешивает типы нарушений с разными порогами (24 ч / 7 дн).

**Предзаказы** — A (4 цифры + воронка). B полезен при закупке, но это скорее экран «Поставок», а не метрик.

**Маржа** — A (водопад) как основа, из B взять блок «Где теряю». Водопад отвечает на «куда уходят деньги», расходящиеся столбцы B — на «где теряю»; вместе закрывают вопрос владельца. Спорно: деньги не округлять скрытно (на сводных «≈»), правила «известной себестоимости» не менять.

**Журнал → Админка** — A (сегмент «Рискованные», пресеты, «Фильтры (N)»). Спорно: список рискованных кодов на клиенте (`AUDIT_RISKY`) — позже лучше параметром сервера. Панель деталей из B полезна на широких экранах.

**Журнал → Бот и сайт** — A сейчас, B как следующий шаг. Группировка по заказу/клиенту (B) отвечает на «что случилось с клиентом», но меняет модель ленты и требует группировки на бэкенде.

**Модалки** — A (шторки/поповеры) по умолчанию. Спорно: «Скрыть» без подтверждения (B) допустимо только при надёжной отмене на сервере; `useHideDeadProduct` — мутация, лучше оставить подтверждение шторкой.
