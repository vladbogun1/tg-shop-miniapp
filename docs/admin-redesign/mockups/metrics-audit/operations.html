Раздел 7. Проблемы: самые срочные блоки стоят посередине, строка без ссылки на заказ, p90 понятен только из подсказки.

Вариант A: срочное наверх, строки — заказы

Оба блока нарушений поднимаются вверх, у строки есть сумма и «ждёт N ч» (красный > 72 ч), клик открывает заказ. Структура экрана почти прежняя — меньше переделок.
