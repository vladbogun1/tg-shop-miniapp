Промокоды — список

Экран «Промокоды»: быстрое выключение, один sticky-ряд, заказы кода вне карточки. Меню «⋯» и удаление показаны на втором телефоне варианта A.

Вариант A — «Плотная строка + Toggle + панель заказов»

Один sticky-ряд управления, строка = код · скидка · прогресс · срок · Toggle · «⋯»; заказы кода — правая панель (шторка на телефоне).

Вариант B — «Группы как чаты + мастер–деталь»

Телефон: список групп-входов (Мои / Персональные / За отзывы / Из кейса) → внутри крупные карточки с тумблером. Десктоп: три колонки группы | коды | редактирование на месте.
