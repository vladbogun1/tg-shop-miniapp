AuthGate → Login → CredentialsStep → CodeStep / SetupStep. Порядок шагов и API не меняются, только вёрстка и тексты. Внизу — плашка dev-login.

A
Вариант A: Одна карточка, шаги внутри: как сейчас, но с inline-ошибкой (role=alert), «глаз» и Caps Lock, логотип 168 px, форма прижата к верху при клавиатуре; таймаут Telegram-входа 5 с.
B
Вариант B: Мастер с прогрессом и кнопкой в зоне большого пальца: на телефоне крупное одно поле на экран, «Далее» приколота к низу над клавиатурой; на десктопе — разделение: слева бренд и подсказки, справа форма.
Минус: больше шагов на телефоне; порядок шагов в логике не меняется (на нём e2e), только раскладка.
A / B
Вариант A / B: dev-login — только локальный стенд. A: плашка внизу слева; B: тонкая оранжевая полоса по верху.
