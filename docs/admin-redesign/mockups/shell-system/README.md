# Макеты: оболочка и системные экраны

Статичные HTML (без зависимостей), открывать `index.html`. Источник — `../../shell-system.md`.
Рамки: телефон 390, планшет 820, ноутбук 1024, десктоп 1440, большой 1920 (десктопные уменьшены `zoom`).
Скриншоты проверки — `_shots/`. Макеты генерируются скриптом; правьте HTML напрямую или просите перегенерировать.

| Экран | Файл | Рекомендация | Что спорно |
|---|---|---|---|
| Командная палитра | palette.html | **A**: одна лента с группами проще в сборке (nav-config + серверный поиск) и привычна. Превью из B — вторым этапом. | B требует эндпоинта превью и шире 560 px; плитки-входы на телефоне хороши, но их можно взять и в A. |
| Сайдбар и рейл | sidebar.html | **A**: меньше изменений, закреплённое + профиль решают реальные боли (подвал 170 px, «Выйти везде»). | B красив, но это новая навигационная модель и два уровня на 1024 съедают ширину; закреплённое теряет смысл. |
| Верхняя панель | topbar.html | **A**: крошки + поповер «Что ждёт» — дешёвый и понятный выигрыш. | B: шапка ~100 px и перенос PageHeader в шапку — согласовать с «Заказами». |
| Нижняя панель и «Ещё» | tabbar-more.html | **B** на телефоне — совпадает с принятым направлением («как чаты»), превью-строки дают смысл; на планшете — рейл. | B — два тапа до пункта; плитки A быстрее для тех, кто знает, где что. |
| Баннеры | banners.html | **A**: очередь по одному, плашка 52 px — логика показа не меняется. | B убирает навязчивость, но push-подписок будет меньше; «×» = «позже 30 дней» нужно решить с владельцем. |
| Вход и dev-login | login.html | **A** (inline-ошибка, глаз, Caps Lock, таймаут Telegram) — P1 и дёшево. Мастер B — для 2FA-настройки. dev-login: плашка A. | B на телефоне — лишний шаг, порядок шагов для e2e не меняется. |
| Админы + модалки | admins.html | **A** для таблицы/сводки и шторок; из B взять мастер приглашения «1 из 2». | B (мастер-детали) убирает «···», но делает «Сбросить 2FA» на клик длиннее. |
| Инциденты | incidents.html | **A** на телефоне/планшете (карточки с «Что сделать» сверху + чипы-шаблоны); **B** на 1280+ для разбора пачкой. | B требует состояния «выбран» (`?id=`), для 1–2 инцидентов список лишний. |
| Мой аккаунт | account.html | **B** на телефоне (список-вход, как «Настройки» Телеграма), **A** на десктопе (две колонки). | B на десктопе показывает меньше за раз; перенастройка 2FA — модалка с прогрессом в обоих. |

Общее: тач-цели 44 px, данные придуманы (заказы, суммы, имена), иконки — inline SVG.
Баннеры/палитра на 320 px и 2560 px отдельно не рисовались — проверять в `shop-ui-qa` при реализации.
