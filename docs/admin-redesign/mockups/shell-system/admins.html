Админы: список, приглашение, подтверждение кодом

AdminsScreen, TeamList, RowMenu, InviteModal, CodeConfirmModal. Опасные действия остаются за кодом; переключатель «Финансы» не прячем.

A
Вариант A: Сводка-чипы + одна таблица/карточки: «Активных 5 · без 2FA 1 · ждут входа 2» — чипы-фильтры; до 1280 px скрываем «Создан» и «Устройства»; на телефоне компактная карточка, «Пригласить» — в нижней панели над TabBar.
A · модалки
Вариант A · модалки: Те же модалки, но по-разному на устройствах: на телефоне «Пригласить» — полный экран с sticky-кнопкой, подтверждение кодом — нижняя шторка с именем того, кого касается.
B
Вариант B: Список как чаты → карточка человека: на телефоне строка = человек с превью «роль · 2FA · был», тап — экран человека, где все действия — строками (вместо «···»). На десктопе — мастер-детали: список слева, справа карточка.
Спорно: два клика вместо одного для «Сбросить 2FA»; зато нет мелкого «···» и опасное отделено. Пригласить — двухшаговая форма (кто → роль и код) в шторке.
B · модалки
Вариант B · модалки: Приглашение — мастер из 2 шагов; подтверждение кодом — отдельным экраном с крупными слотами и именем.
