Инциденты (SUPER)

IncidentsScreen / IncidentCard. Бейдж «Инциденты» в nav-config — для главного админа, это сигнал про деньги.

A
Вариант A: Карточки: «Что сделать» первым и подсвеченным, «Факты» и «Гипотеза» свёрнуты; фильтр по серьёзности; заказ — кнопкой; решение — шаблонами-чипами, на телефоне в шторке с sticky-кнопкой. Бейдж в меню — для SUPER.
B
Вариант B: Разбор пачкой: список + детали (deep-link ?id= из push остаётся). Слева компактный список по серьёзности, справа выбранный инцидент; на телефоне — список-вход как чаты, тап → экран инцидента.
Спорно: состояние «выбран» и хождение между ними; для одиночных инцидентов список — лишняя рамка.
