Сайдбар и рейл

Подвал → профиль, закреплённое/недавнее, бейджи, ноутбучный рейл. На телефоне — шторка «Ещё» (отдельный экран).

A
Вариант A: Одна колонка: «Закреплённое» + профиль-блок. Звёздочка у любого пункта; подвал из 4 строк → один блок «профиль» с меню (Выйти везде — только за подтверждением).
На телефоне сайдбара нет — там шторка «Ещё», см. «Нижняя панель и Ещё». Подвал освобождает около 100 px высоты.
B
Вариант B: Два уровня, как в Slack/Linear: узкий рейл с 5 разделами (бейдж = сумма раздела) + вторая колонка пунктов выбранного. «Главное» (4 ежедневных) открыт по умолчанию — закреплять не нужно.
Закреплённое заменено логикой «Главное = ежедневное»; персонализация позже. Меню профиля — как в A (по аватару внизу рейла).
