Мой аккаунт

AccountScreen: профиль, 2FA, пароль, устройства, история входов. Смена пароля и перенастройка 2FA — критичные потоки, API не меняется.

A
Вариант A: Сегменты сверху + панели: на телефоне sticky-сегменты Профиль · Безопасность · Устройства · История, «Опасная зона» внизу (из сайдбара «Выйти везде» убран); пароль и 2FA — шагами в шторке «1 из 2».
B
Вариант B: Настройки как в Телеграме: на телефоне — список-вход (круг-иконка, название, статус-превью), тап — отдельная страница со «‹». На десктопе — слева меню разделов, справа выбранный (settings-раскладка).
Спорно: на десктопе меньше информации сразу (вместо двух колонок — по разделам); зато нет длинной ленты.
