Баннеры установки и push

Сейчас — две карточки по ~130 px в потоке и фиксированный UpdateBanner над вкладками. Логику показа не меняем, только вёрстку.

A
Вариант A: Очередь: максимум один баннер (Обновление › Push › Установка). Плашка 52 px под шапкой, подробности раскрываются; «×» везде = «позже на 30 дней», «Не напоминать» — внутри раскрытия.
B
Вариант B: Баннеры уходят с экрана: в потоке ничего не висит. На «Ещё»/аватаре — точка; внутри карточка «Приложение» (установка, push, версия) — каждое действие в своём месте, одним местом для настроек.
Спорно: push-подписки без напоминания соберут меньше. Компромисс — единожды показать плашку из A, затем только точку.
