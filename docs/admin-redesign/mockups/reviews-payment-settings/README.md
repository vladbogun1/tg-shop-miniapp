# Макеты: Отзывы, Оплата, Настройки

Статичный HTML+CSS, без скриптов и внешних зависимостей. Старт — `index.html`. Отчёт-источник: `../../reviews-payment-settings.md`.
Размеры: телефон 390, планшет 820, ноут 1440, большой 1920 (оплата). Скриншоты проверки — `_shots/`.

## Отзывы (`reviews.html`)
- **Экран — рекомендую A** (очередь + деталь, клавиши, автопереход). Один сценарий на всех экранах, ложится на отчёт и на `use-queue-hotkeys`. На телефон берём из B свайп-строки как P2.
  Спорно: B (стопка) красивее для «по одному», но на ноуте не видно очередь; свайп = риск случайной публикации, нужен undo-toast.
- **Телефон**: вход-список статусов из B совпадает с принятыми «Заказами»; режим «По одному» из A — для быстрого разбора. Можно объединить.
- **Ответ — рекомендую A** (чипы-шаблоны + «Ответить и опубликовать»): проще, шаблоны видны без знания команд. Спорно: слэш-меню (B) удобно клавиатуре, но неочевидно; шаблоны пока в localStorage.
- Спорно в обоих: строка бонуса требует поле `bonusEligible` от бэка.

## Оплата: экран (`payment.html`)
- **Рекомендую A** (аккордеон + Sheet): минимальное изменение, 6–8 способов на экране, статус всегда в шапке, справка в поповере (колонка только на 1920).
- B (мастер–деталь + превью покупателя) полезен для предоплаты, но способов мало — может быть избыточен; превью можно вынести в A как блок внутри раскрытой строки.
- Спорно: красный режим пилюли при ошибке monobank — блокировать ли экран баннером.

## Оплата: модалки (`payment-modals.html`)
- **Корректировка оплаты — A** (сегменты + «Наложка после» в footer): меньше высота, проще на 320 px. B нагляднее по деньгам, но выше; из B взять красный `role="alert"` на шаге 2.
- **Возврат — B** (по позициям) если позиции доступны в модалке, иначе A с пресетами. Спорно: частичный возврат произвольной суммы должен остаться («ввести вручную»).
- **Удаление способа — B** (Выключить / Удалить навсегда): снимает вопрос «что будет с заказами». A — запасной, если нужен минимум.

## Настройки (`settings.html`, `settings-bot.html`)
- **Экран — рекомендую A** (оглавление/чипы + плотные строки + DirtyBar): прямо отчёт, P1. На телефоне из B стоит взять список групп как «чаты» вместо горизонтальных чипов.
  Спорно: B (панель «Изменения») полезна при десятках правок, но громоздка и ломает «всё или ничего» на проверке; можно оставить как «Показать» в DirtyBar.
- **Тексты бота — рекомендую A** (редактор + пузырь): привычный сценарий. B (3 колонки) — для сверки переводов, спорно по ширине и дублированию предпросмотров.
