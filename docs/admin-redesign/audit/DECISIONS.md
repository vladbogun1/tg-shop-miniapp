## Правило для «заметных» и «мелочей» (решение владельца 2026-11-07)
Все остальные пункты отчётов `audit/*.md` (заметные и мелкие) — ВОЗВРАЩАТЬ ПО УМОЛЧАНИЮ при реализации экрана: то, что было в старом коде, остаётся.
Исключения — не возвращать, а убирать/исправлять в макете:
- то, что дизайнеры выдумали и чего нет в коде или бэкенде (поля API, которых нет: `bonusEligible`, счётчики, поиск по журналу, IP и т.п.; кнопка «Импорт» товаров; разрез «Деньги в пути»);
- расхождения текстов подсказок с кодом — брать текст из кода.
Пункты, которые требуют изменения бэкенда, не входят в редизайн экрана; их выносить отдельной задачей.
Перед реализацией каждого экрана: открыть его `audit/<тема>.md` и пройти по пунктам как по чек-листу.
