# Сравнение товаров

Ветка `compare` (2026-10-09). Сайт и Mini App; без миграций, бэкенд — одна строка в белом списке аналитики.

## Что видит покупатель

| Где | Сайт | Mini App |
|---|---|---|
| Карточка в каталоге | круглая ⚖ в правом нижнем углу фото (свободный угол: слева «Уцінка», сверху наличие и скидка) | то же; бейдж «Уценка» переехал в левый нижний угол |
| Страница / окно товара | кнопка «Порівняти» под «В кошик / Купити», после добавления — «Порівняння · N →» | чип «Сравнить» рядом с брендом, после — «Сравнение · N ›» |
| Вход в сравнение | от md: ⚖ со счётчиком в шапке; телефон: ⚖ в липкой строке «Фільтри · сортування» каталога и первый пункт бургер-меню | вкладка «Сравнить» со счётчиком в таб-баре (только пока список не пуст), работает с любой страницы |
| Тост после добавления | «Додано до порівняння · N» + кнопка «Порівняти» | то же |
| Окно сравнения | модалка по центру (≤1240 px); на телефоне — на весь экран | полноэкранный слой как карточка товара; «Назад» Telegram закрывает |

Плавающих кнопок нет намеренно: любая кнопка поверх сетки при прокрутке закрывает ⚖ карточек.
Тост — один элемент, пока сообщения идут подряд (новое меняет только текст), и кнопка в нём есть
всегда: иначе при быстрых добавлениях он прыгал вбок и менял ширину.

Проверено на 320/360/390/768/1024/1280/1440 px, uk/ru/en: без горизонтального скролла, кнопки
шапки и карточек не вылезают и не переносятся. Попутно (было и в master): на 320 px корзина в шапке
сайта упиралась в край (пустые элементы шапки брали по 8 px отступа), «В корзину» переносилось в две
строки (иконка скрыта < 360 px), в Mini App «Уценка» наезжала на «В наличии».

В окне: вкладки по корневым категориям (Миші 3 · Клавіатури 2), переключатель «Лише відмінності»
(запоминается в localStorage), «Очистити» в два нажатия (второе — подтверждение, 3 с),
«Поділитися» (только сайт) — ссылка `?compare=slug1,slug2` на любую страницу сайта: товары
добавляются, окно открывается, параметр убирается из адреса.

Строки: «Основне» (ціна — найнижча зелёным, рейтинг — найвищий зелёным, наявність, бренд, стан —
только если есть уценка) и все `comparable` характеристики категорий товаров, сгруппированные как
на странице товара. Пустые у всех строки скрыты; одинаковые у всех — приглушены.

Раскладка: одна прокручиваемая в обе стороны область. Широкий экран — липкая колонка подписей
слева (200 px), колонки 210–300 px, пустая колонка «+ Додати товар» пока товаров < 4. Телефон —
две колонки ровно на ширину, свайп по одной колонке (scroll-snap), подпись строки отдельной
строкой НАД значениями и не уезжает при свайпе. Шапки товаров (фото, цена, «В кошик») уезжают
вверх, их место занимает компактная полоса «миниатюра · название · цена» (кликабельна).

## Хранение

`localStorage["compare-v1"]` (zustand persist), отдельно на каждом устройстве и в каждом
приложении — без аккаунта, гости тоже сравнивают. Хранятся только `{id, group, addedAt}`:
цены и характеристики всегда берутся свежими из каталога при открытии, исчезнувшие из каталога
товары молча выпадают (`prune`). Группа = id корневой категории (Клавіатури › Магнітні и
› Механічні сравниваются вместе по объединению характеристик).

Лимиты (`shared/src/compare.ts`): 6 товаров в группе, 24 всего — отказ показывается тостом.
Сайт синхронизирует вкладки браузера через событие `storage`.

Почему не сервер: сравнение — короткоживущий черновик выбора; серверная синхронизация (как у
корзины) потребовала бы таблицу, миграцию и API, а пользы мало. Если понадобится — формат
`CompareEntry` уже годится для `PUT /api/me/compare`.

## Код

- `shared/src/compare.ts` — группы, лимиты, строки таблицы (`compareSections`, `onlyDifferences`).
- Сайт: `site/lib/compare.ts` (стор + тост), `site/components/compare/{CompareModal,CompareTable,CompareToggle}.tsx`,
  кнопка в `Header.tsx`, тост с кнопкой — `components/ui/Toast.tsx` (`toast(msg, kind, action)`).
  Данные: `GET /api/public/products?all=1&view=card` + `/api/public/catalog/schema` (только когда окно открыто).
- Mini App: `frontend/lib/compare.ts`, `frontend/components/compare/{CompareSheet,CompareBits}.tsx`;
  данные — уже загруженный `["products"]`.
- Аналитика: события `compare_add` (productId) и `compare_open` (count) в `client_events`; для сайта
  они добавлены в белый список `StructuredEvents.WEB_ALLOWED` (единственная правка бэкенда — до его
  релиза сайт эти события просто не записывает).
