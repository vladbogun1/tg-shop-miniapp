# Встроенный ИИ в админке

Замена ручного «скопировать промпт → ChatGPT → вставить ответ». Промпты строит админка (те же сборщики, что для
копирования), бэкенд ведёт разговор с моделью и сам ищет в интернете, ответ разбирают те же парсеры.

## Как устроено (модуль `backend/.../ai`)

| Часть | Класс | Что делает |
|---|---|---|
| Модель | `infra/MiniMaxChat` | MiniMax M3.1 Flash через Anthropic-совместимый `POST /v1/messages`. Таймаут 180 с, повтор 1 раз на сетевую ошибку/502–504 и 1 раз на 429/529 |
| Поиск | `app/WebSearch` | цепочка провайдеров: `infra/SearxngSearch` (наш SearXNG, бесплатно) → `infra/SerperSearch` (Google через serper.dev, $0,001). Следующий спрашивается, только если предыдущий упал или ничего не нашёл. Упавший отдыхает 10 минут |
| Страницы | `app/WebPages` | своя загрузка через `media.app.RemotePages` (внутренние адреса запрещены на каждом редиректе) → при 403/429/JS-заглушке — `infra/JinaReader` (r.jina.ai) |
| Разговор | `app/AiAgent` + `app/ResearchTools` | инструменты `search`/`open_page`, бюджет 3 поиска и 4 страницы на товар; запрос сверх бюджета — отказ и следующий ход обязан быть ответом; битый ```json — один ход-починка без инструментов |
| Задачи | `app/AiJobs` | вопрос идёт в фоне (3 одновременно, 10 в очереди, дальше «ИИ занят»), админка опрашивает задачу; хранится час в кэше |
| Журнал | `app/AiUsageLog`, таблица `ai_usage` (V83) | каждая модель/поиск/страница — строка: токены, стоимость, OK/EMPTY/FAILED. Лимит расхода на месяц проверяется перед каждым вызовом модели |

## API (`/api/admin/ai`, любой админ)

- `POST /jobs` `{feature, prompt, effort: low|medium|high, researchItems: 0..10}` → задача `RUNNING`.
  `researchItems` = сколько товаров в промпте (масштабирует бюджет поиска); 0 — без инструментов.
- `GET /jobs/{id}` → `RUNNING` или `DONE` с ответом (текст, стоимость, токены, сколько поисков/страниц); упавшая задача отвечает своей ошибкой.
- `GET /status` → есть ли ключ, провайдеры поиска (включён / отдыхает), расход за месяц по провайдерам и результатам — тут счётчик пустых и упавших поисков.
- `POST /search-test` `{query}` → один запрос через цепочку, как его видит модель.

## Настройки (env → `app.ai.*`)

| Переменная | Что | Пусто |
|---|---|---|
| `AI_MINIMAX_KEY` | ключ MiniMax | кнопки ИИ отвечают «ИИ не настроен» |
| `AI_SEARXNG_URL` | наш SearXNG с `formats: [json]` | без бесплатного поиска |
| `AI_SERPER_KEY` | ключ serper.dev | без запасного поиска |
| `AI_MONTH_LIMIT_CENTS` | лимит за календарный месяц, центы USD (по умолчанию 1000 = $10; 0 — без лимита) | — |

Цены модели (`app.ai.model.input-per-m` и т.д.) — в micro-USD за миллион токенов, по умолчанию MiniMax M3.1 Flash.

## Замер (ноябрь 2026, `scripts/ai-bench`)

24 товара, свои инструменты поиска: effort `medium` — 88 % верных характеристик, ≈0,20 ₴ за карточку;
`low` — 83 %. Для карточек берём `medium`, для разбора накладных — `low`.

Известные слабые места: модель иногда не открывает официальную страницу, путает единицы (256000 вместо 256 для
частоты сканирования) и оставляет пустым редкое. Следующий шаг — проверка правдоподобия чисел по диапазонам каталога.
