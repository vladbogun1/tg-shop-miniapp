# Скриншоты для README

Положи сюда PNG-скриншоты приложения с этими именами — они подхватятся в корневом `README.md`:

| Файл | Что на нём |
|---|---|
| `catalog.png` | Каталог (Mini App) — стекло на цветном фоне, поиск, теги |
| `product.png` | Карточка товара (fullscreen, галерея) |
| `cart-checkout.png` | Корзина / пошаговый чекаут (Новая Почта, оплата) |
| `account-chat.png` | Аккаунт → заказ → чат с админом |
| `admin-board.png` | Админка: канбан-доска заказов |
| `admin-order.png` | Админка: разворот заказа (детали + таймлайн + чат) |
| `admin-metrics.png` | Админка: метрики (графики) |
| `bot-card.png` | Уведомление-карточка заказа в Telegram-канале |

Рекомендуемая ширина мобильных скринов ~390px, десктопных ~1200px.
