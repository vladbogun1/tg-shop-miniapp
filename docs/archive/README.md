# Архив документации

Исторические документы. Описывают прошлые состояния проекта (v2, июнь–сентябрь 2026) и **не
соответствуют текущему коду** — пути, домены и решения внутри могут быть устаревшими. Перенесены
сюда при чистке 2026-10 (`docs/CLEANUP-AUDIT-2026-10.md`). Реквизиты оплаты из них вырезаны.

- `HANDOFF.md` — передаточный документ v2 (июнь 2026): видение, решения, разбор кода того времени.
- `ДИЗАЙН-ДОКУМЕНТ-старый-проект.md` — разбор старого `tg-shop-miniapp` перед переписыванием.
- `ДИЗАЙН-ДОКУМЕНТ-новый-проект.md` — план переписывания с нуля и редизайна (июнь 2026).
- `AUDIT-FIXES.md` — чек-лист работ по аудиту 2026-09-17 (ветка `audit-fixes`).
- `UI-FIXES.md` — второй заход по UI-дефектам (ветка «улучшение»), на правила из него ссылается код.
- `I18N.md` — план и правила перевода интерфейса на uk/ru/en (ветка `i18n`).
- `FEATURE-order-gifts-discounts-stockvalue.md` — дизайн подарков к заказу, скидок от админа и сводки склада.
- `NEO-frontend.md` — гайд по стилю Neo-Brutalism для Mini App (v2); раздел про framer-motion ещё актуален.
- `NEO-frontend-admin.md` — заглушка «Neo-Brutalism v2 заменён на v3» для админки.
- `brand-v2/` — бренд MAXSOLCH v2 для Telegram (аватар бота, обложка Mini App, скрипты сборки); актуальный бренд — `docs/brand/v3/`.
