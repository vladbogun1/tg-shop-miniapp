# Маскот на главной — режиссёрский сценарий (v2, после замечаний владельца 08.10.2026)

Замечания к v1 (что исправляем):
- хиро: нет сюжета; коробка приезжает вплотную к качку, половина панели пустая; погрузчик не опускает вилы;
  нет распаковки — из коробки должны веером вылетать мышки, клавиатуры, наушники и т.д.;
- категории: спрайты «не в тему», вставлены криво (выглядывают из-за края, обрезаются, перекрывают текст) —
  для каждой категории нужен СВОЙ рисунок по смыслу (генерация ChatGPT через `/mascot-toon`);
- «Що кажуть покупці»: `discord` не в тему;
- перед показом владельцу — покадровая сверка КАЖДОЙ анимации (мешает ли, логична ли, не обрезается ли).

Общие правила: пиксель-арт, `image-rendering: pixelated`, только целые масштабы (`--px`), все координаты ниже — в
арт-пикселях; персонажи в профиль/¾; ни один спрайт не выходит за свою панель/слот и не перекрывает текст;
`prefers-reduced-motion` → статичный «лучший кадр» сцены (не пустая сцена).

## 1. Хиро «Доставка ChiSetup» — холст 160×88, пол y=76, цикл 12.0 с

Раскладка по ширине (используем ВСЮ панель):
```
x: 0 ─────── 40 ─────────── 80 ─────────── 120 ──────── 160
   │ въезд/  │ погрузчик     │ КОРОБКА x≈76  │ качок x≈128 │
   │ выезд   │ стоит x≈18–58 │ (центр сцены) │ (справа)    │
```
Персонажи в полный рост: качок ≈46 px высотой (кадры `frames/bn4_poor`, `bn5_donate`), погрузчик ≈34 px
(`frames/bn3_hauler`, 8 кадров: вилы вверх/вниз, лица, маячок), коробка ≈20 px (`frames/bn_box` f00–f02),
товары 10–16 px (`frames/bn2_products` + сгенерированный лист `products`), FX — `frames/bn3_fx_a/b`.
Между коробкой и качком ≥ 30 px пустого пола: товары разлетаются именно в этот промежуток и над ним.

Масштаб: `--px` 2 (мобайл, 320×176), 3 на ≥768 (480×264), 2 на 1024–1279 (колонка уже), 3 на ≥1280.

## 2. Категории — свой персонаж-сценка на каждую (генерация)

Слот: правый нижний угол плитки, фиксированный бокс **48×40 арт-px × 2** (96×80 css) — на всех экранах.
Спрайт целиком внутри слота, ничего не выглядывает из-за краёв, не перекрывает название и «N товарів»
(счётчик ограничен левой половиной). SVG `CategoryArt` убираем — слот занимает его место.
Покой: кадр 0 (+ моргание раз в ~4 с у персонажей). Hover/focus (и `:active` на таче): проигрывается действие,
4 кадра, ~0.6 с, затем возврат в покой. Тач: покой, без движения.

| Категория | Сценка (4 кадра) |
|---|---|
| Мишки | качок резко «флик» мышкой вбок, у мышки след-движение, щелчок-вспышка |
| Глайди | робот приклеивает белые глайды к брюшку перевёрнутой мышки, блеск |
| Килимки | мышка скользит по ковру слева направо, за ней лёгкий след |
| Скляні пади | робот протирает стеклянный пад тряпкой, блик бежит по стеклу |
| Механічні клавіатури | робот быстро печатает, над клавишами «клик»-искры |
| Магнітні клавіатури | клавиша нажимается, вокруг магнитные дуги-поля (бирюзово-оранжевые) |
| Кейкапи | качок съёмником вытаскивает кейкап, тот подпрыгивает |
| Навушники | качок в наушниках кивает в такт, вылетают ноты |
| Кабелі | робот сматывает витой кабель-«пружинку» |
| Рукави | качок натягивает рукав на руку и показывает бицепс |
| Дуйки | компактный воздуходув-«дуйка» сдувает пыль с клавиатуры, облачко пыли |
| Крісла | качок откидывается в игровом кресле (есть `frames/bn4_chair`) |
| Столи | робот поднимает столешницу стола (подъёмный стол едет вверх) |
| Уценка | робот штампует ценник «−%» на коробку |

## 3. «Що кажуть покупці»

Вместо `discord`: качок с телефоном читает отзыв → над ним по одной загораются 5 звёзд → большой палец.
Покой — кадр «читает»; при спотлайте «легенды» (5★) — звёзды + палец (уже есть хук `data-legend`).
Слот у заголовка 40×32 × 2, не перекрывает счётчик/кнопку паузы.

## 4. Остальное — проверить покадрово, оставить если логично

- «Чому в нас»: доставка → погрузчик с коробкой ✔, оплата → монета-сердце ✔, гарантия «перевіряємо кожен
  товар» → качок с лупой и мышкой (`devices`, логичнее «проверки», чем робот у ПК), чат → качок с телефоном ✔.
- Кнопка «В каталог»: монетка — оставить, проверить, что не перекрывает текст соседней кнопки на мобайле.
- Подвал: пылесос — проверить, что не наезжает на ссылки/текст и не мельтешит.
- Пустая корзина / 404 — проверить покадрово.

## 5. Приёмка (обязательна до показа владельцу)

Для каждой анимации: снимок кадров каждые 100 мс (Web Animations API: пауза + `currentTime`) на 1440 и 375 →
контакт-лист → проверка: нет обрезки, нет перекрытия текста, ничего не прыгает между кадрами, траектории
логичны, пол один, масштаб целый, луп бесшовный, reduced-motion показывает осмысленный кадр.
