# Аудит i18n покупательской части (2026-10-07, ветка `sij-i18n`)

Повод: владелец нашёл непереведённые слова после фич monobank / чеки / отмена покупателем / поддержка /
отзывы / Новая Почта / push, а информационные страницы сайта (футер) были только на украинском.

Админка (`frontend-admin/`), карточки в канал продавца, push в приложение админа, список отгрузки —
русские **сознательно** (см. `archive/I18N.md`, п. 4) и в аудит не входят.

## Как искали

1. Скан кириллицы вне комментариев во всех `.ts/.tsx/.java` (`frontend/`, `site/`, `shared/src`,
   `backend/src/main/java`; словари `i18n/` исключены) — 110 строк в фронтах и `shared`, 639 в бэкенде.
2. Эвристический скан английского текста в JSX: текстовые узлы, `aria-label/title/alt/placeholder`,
   `toast/setError(...)`, литералы `message/title/label: "…"` — 11 строк.
3. Сверка словарей (`frontend/i18n`, `site/i18n`): одинаковые ключи, кириллица в `en`, буквы ы/э/ъ/ё в `uk`,
   значения `uk == ru` и `en == ru`, одинаковые `{плейсхолдеры}`.
4. Бэкенд: литералы в исключениях на путях покупателя (`/api/me/*`, `/api/orders`, `/api/payments/*`,
   отзывы, поддержка), ключи бандлов, которые заведены, но нигде не используются (так нашлись
   неподключённые `api.order.unavailable / variantRequired / deliveryRequired / fieldRequired …`).
5. Ручной проход по местам, где фронт показывает текст сервера «как есть»: `rejectReason`,
   `paymentOptionTitle`, `lastPreview`, `statusText` чеков.

Итого по существу: **37 мест** реально видны покупателю и были не на его языке (+ 5 информационных
страниц × 2 языка). Остальное — админское, не UI (ключевые слова, регулярки, фиды) или уже было
переведено локальной картой.

## Сознательно оставлено

- **Описание платежа и корзина в monobank** (`payment/OnlinePaymentService.java:177, 231–232, 261`,
  `payment/MonobankClient.java:65` — «Оплата замовлення #…», «шт.»): украинский для всех. Это текст
  банковской страницы и фискального чека (Вчасно.Каса), а чек по закону — на государственном языке.
- **Причины отмены, которые уходят продавцу** (`CANCEL_REASONS[].ru` в `frontend/app/account/orders/[id]/page.tsx:517`
  и `site/components/account/OrderDetailView.tsx:243`): русский — для продавца; покупатель видит перевод
  (`cancel.reason.*`, и теперь на карточке заказа — через `CustomerRejectReason`).
- **Свободный текст людей**: причина отклонения, которую написал админ, комментарий к отказу в отмене,
  текст рассылки, ответы в чате — не переводятся (как и раньше, `archive/I18N.md` п. 4).
- **`shared/src/orders.ts`, `format.ts`, `http.ts`, `money.ts`** — русские значения по умолчанию для админки;
  оба фронта передают свои переведённые тексты/локаль. `telegram-html.ts`, `product-brand.ts` — админка/регулярка.
- **`site/lib/seo.ts` `CATEGORY_SEO`**, адрес в JSON-LD — уже локализованы картой uk/ru/en в коде (SEO-данные,
  не интерфейс). `site/components/home/CategoryArt.tsx` — ключевые слова для подбора иконки, не текст.
- **Фиды** (`site/lib/feeds.ts`, «В наличии», «Нова Пошта») — язык задан форматом фида (Hotline / Google uk/ru).
- **`frontend/app/layout.tsx:32`** — `<meta description>` Mini App на украинском: страница не индексируется,
  язык интерфейса выбирается на клиенте.
- **`shared/src/brand/preloader.ts:61`** `aria-label="Loading"` — у контейнера прелоадера `aria-hidden`,
  скринридер его не читает.
- **`BroadcastService.DEFAULT_BUTTON`** — кнопка рассылки уже переведена локальной картой uk/ru/en.
- **`TgInitDataValidator`** (`initData …`) — английские диагностические тексты 401; фронты вместо них
  показывают свой `common.sessionExpired`.

## Не переведено (контент из БД) — отметка для владельца

- Названия/описания товаров, вариантов, категорий, способов оплаты — слой `content_translations`
  (`docs/CONTENT-I18N.md`, вкладка «Переводы»); это отдельная история.
- **`support_threads.subject`** для вопроса о товаре = русское название товара на момент вопроса
  (`SupportService.java:195`), в списке обращений покупателя оно остаётся русским. Решается так же, как
  позиции заказа (`TranslationService.orderItemNames`), — отдельной задачей.
- **Адреса отделений Новой Почты** — из API НП, украинские (адрес есть адрес).
