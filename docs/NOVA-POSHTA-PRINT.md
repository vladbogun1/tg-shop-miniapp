# Печать этикеток Новой почты

Статус (2026-10-23): печать через браузер готова; тихая печать на термопринтер — описана, не сделана
(термопринтера у владельца пока нет).

## Что есть сейчас

- «Друк етикетки» в заказе и «Друк етикеток» на «К отправке» → бэкенд `GET /api/admin/shipments/labels?orderIds=…&format=…`
  забирает у НП **один PDF** на все выбранные ТТН и отдаёт его админке. Ключ API в браузер не уходит.
- Форматы: `100x100` (термоэтикетка, по умолчанию), `85x85` (4 этикетки на листе A4 — обычный принтер),
  `a4` (полная ТТН). До 100 ТТН за раз.
- PDF открывается в новой вкладке → Ctrl+P. Для термопринтера в диалоге: размер бумаги 100×100 мм, поля 0, масштаб 100 %.
- На демо (`NP_DRY_RUN=true`) номера `DRY…`, PDF — заглушка с номерами.

## Тихая печать (когда купят термопринтер)

Браузер не умеет печатать без диалога, поэтому нужен маленький агент на компьютере, где стоит принтер.

### Вариант A — QZ Tray (готовый агент)

1. Поставить QZ Tray (qz.io) на ПК упаковщика, выбрать принтер этикеток (Xprinter / Zebra / TSC …) в Windows,
   размер бумаги 100×100 мм.
2. В админке (будущая настройка «Тихая печать», по умолчанию выключена): имя принтера и формат.
3. Админка подключает `qz-tray.js`, получает PDF с бэкенда (как сейчас) и шлёт его в QZ:
   `qz.print(qz.configs.create(printer, {size:{width:100,height:100}, units:'mm'}), [{type:'pixel', format:'pdf', flavor:'base64', data}])`.
4. Чтобы QZ не спрашивал «разрешить?» на каждую печать, запросы подписываются: сертификат и закрытый ключ сайта
   (у QZ — платная подпись или свой самоподписанный сертификат, добавленный в QZ на этом ПК). Закрытый ключ — только
   на бэкенде: эндпоинт `POST /api/admin/print/sign` подписывает строку от QZ (SHA-512). В репозиторий ключ не класть.

### Вариант B — свой мини-сервис

Небольшой сервис на ПК упаковщика (Node/Go, автозапуск), слушает `http://127.0.0.1:<порт>/print`, принимает PDF и
печатает через `SumatraPDF.exe -print-to "<принтер>" -print-settings "noscale" file.pdf`. Админка шлёт туда PDF после
получения с бэкенда. Защита: случайный токен в заголовке, CORS только для `admin.chisetup.com.ua`.

### Автопечать

С тихой печатью можно печатать сразу после «Створити ТТН» / «Створити ТТН для всіх» (отдельная настройка,
по умолчанию выключена). Без агента автопечати нет — только кнопка.

## Что спросить у владельца при покупке

Модель принтера (Xprinter XP-420B / Zebra ZD220 / TSC …), рулон 100×100 мм, на каком ПК печатают, Windows или macOS.
