# Дизайн v3 — ChiSetup

Редизайн v3: новая айдентика **ChiSetup — Gaming Gear & Setup** для сайта (`site/`),
Mini App (`frontend/`) и админки (`frontend-admin/`, §8). Референсы лежат в `docs/brand/v3/reference/`: брендборд (`brandboard.png`),
вывеска (`storefront.webp`) и баннер (`banner.webp`).

**Статус: в проде** с v3.0.0 (04.10.2026) — сайт, Mini App и админка; с v3.1.0 магазин живёт на
`chisetup.com.ua` (`app.` — Mini App, `admin.` — админка). Остатки дизайна v2 (токены `--c2/--c4/--c5`,
`--glow`, неиспользуемые классы) вычищены в 2026-10; архив v2 — ветка `design-v2` и `docs/archive/`.

## 2. Токены (`:root`, одна тема)

Имена токенов сохраняем, меняем только значения. Тогда все компоненты, которые читают `var(--…)`,
перекрасятся сами.

```css
:root {
  color-scheme: dark;

  /* Поверхности: от фона к поднятым слоям */
  --bg:        #0E0E10;   /* страница */
  --surface:   #1A1A1A;   /* карточки, панели   (брендборд #1A1A1A) */
  --surface-2: #222222;   /* поднятые/hover, поля (брендборд #222222) */
  --surface-3: #2A2A2D;   /* нажатое, разделители-плашки */
  --line:      rgba(255,255,255,.08);  /* волосяные рамки */
  --line-strong: rgba(255,255,255,.16);
  --shadow:    rgba(0,0,0,.55);

  /* Текст */
  --ink:   #FFFFFF;
  --muted: #A1A1AA;
  --faint: #6B6B73;

  /* Бренд */
  --accent:      #FF6600;
  --accent-hi:   #FF8533;   /* hover, градиент «Setup» */
  --accent-lo:   #E65C00;   /* pressed */
  --accent-ink:  #0E0E10;   /* текст на оранжевом: тёмный (контраст 6.3:1); белый на #FF6600 = 2.9:1, нельзя */
  --accent-soft: rgba(255,102,0,.12);  /* фон активного чипа/пункта */

  /* Бывшие цветные акценты схлопнулись в бренд; остался только --c3 (Mini App и админка) */
  --c3: #FF8533;   /* было жёлтый: выделения/бейджи → светлый оранжевый, текст на нём тёмный */

  --ok: #22C55E;  --warn: #F59E0B;  --danger: #EF4444;

  /* Статусы заказа: функциональные, те же оттенки, что в админке */
  --st-new: #3F8CF5; --st-approved: #9B6BFF; --st-shipped: #F5A623;
  --st-delivered: #22C07D; --st-rejected: #F0503C;

  --r: 6px;        /* контролы */
  --r-card: 12px;  /* карточки, шторки */
  --chamfer: 10px; /* срез угла у CTA и HUD-рамок */
}
```

Правило контраста: текст на `--accent` всегда `--accent-ink` (тёмный). Оранжевый текст на `--bg`
(`#FF6600` на `#0E0E10` = 6.6:1) допустим для цен, ссылок и заголовков.

## 3. Типографика

- **Exo 2** (`next/font/google`, `subsets: ["latin","cyrillic"]`, веса 500/600/700/800, плюс italic 800 для логотипа)
  отвечает за заголовки, кнопки, цены, табы, чипы, бейджи, навигацию и номера заказов.
- **Inter**: основной текст, описания, поля ввода, юридические страницы.
- Заголовки страниц: Exo 2 800, КАПС, `letter-spacing: .02em`.
- Надзаголовки и метки (eyebrow): Exo 2 600, 11–12px, КАПС, `letter-spacing: .28em`, `--muted`,
  как «GAMING GEAR & SETUP» в брендборде.
- Цены: Exo 2 700, табличные цифры (`font-variant-numeric: tabular-nums`). Текущая цена белая,
  в акцентных местах (BuyBox, итог корзины) оранжевая.
- `font-black` (900) у Exo 2 нет, заменяем на 800. Тотальный капс в тексте убираем: капс остаётся
  у заголовков, кнопок и меток.

CSS-переменные: `--font-display` (Exo 2) и `--font-body` (Inter). Утилита `.font-display`.

## 4. Фон и HUD-детали

- `.scene` (на месте миллиметровки): `--bg` + сетка 1px `rgba(255,255,255,.025)` шагом 48px,
  затухающая к центру через mask-radial, + 2 диагональные оранжевые полосы-«неоны» в
  правом-нижнем и левом-верхнем углах (linear-gradient 135°, blur-free, opacity .35) + мягкое
  оранжевое пятно `radial-gradient(… rgba(255,102,0,.10) …)` под шапкой. Без анимации
  (урок iOS: никаких анимированных fixed-слоёв).
- `.hud-frame`: рамка-«скобки» как вокруг логотипа. Псевдоэлементы `::before`/`::after` рисуют
  уголки, левый-верх белый и правый-низ оранжевый, со срезом. Ставится на hero, пустые состояния,
  экран «заказ оформлен» и блок итога.
- `.chamfer`: `clip-path: polygon(var(--chamfer) 0, 100% 0, 100% calc(100% - var(--chamfer)), calc(100% - var(--chamfer)) 100%, 0 100%, 0 var(--chamfer))`.
  Применяется к главным CTA («В корзину», «Оформить», «Перейти в каталог») и к плашке-иконке CS.
  Отдельный класс есть на сайте и в админке; в Mini App срез встроен в `.nb-accent`.
  У элемента с clip-path обрежется box-shadow, поэтому свечение у таких кнопок делается
  через `filter: drop-shadow(...)` на обёртке или не делается вовсе.
- Тонкие «тех-метки» (декор): короткие оранжевые штрихи 24×2px и точечные ряды у заголовков
  секций, как на баннере. Только на сайте, на главной и в заголовках секций. В Mini App их нет,
  там мало места.

## 6. Ключевые компоненты

**Логотип** (`frontend/components/Logo.tsx`, `site/components/layout/Logo.tsx`): векторный вордмарк
по `reference/logo-target.png` — рисованные контурами наклонные буквы со срезанными углами (не шрифт).
«Ch» белые (#FFF→#D9D9DE), «i» разрезана по диагонали (низ белый, верх-«точка» оранжевая), «Setup» —
градиент `#FF8533 → #FF6600 → #F25500`. Геометрия одна на оба приложения: `shared/src/brand/logo.ts`,
генерируется `docs/brand/v3/tools/gen_brand.py`. Варианты: `full` (HUD-скобки: белые слева-сверху и
справа-снизу, оранжевые справа-сверху и слева-снизу, + подпись GAMING GEAR & SETUP) для входа и
подписи экранов; `compact` (только вордмарк) для шапки и навбара; `mark` (монограмма **CS** в тёмном
скруглённом квадрате со скобками) для favicon, аватара бота и PWA-иконок. Растровые файлы —
`docs/brand/v3/tools/render_brand.mjs`. При первой загрузке страницы оба приложения показывают
прелоадер с `full`-логотипом и полосой загрузки (`shared/src/brand/preloader.ts`).

**Шапка сайта**: `--bg` с blur 12px и полупрозрачностью .85, нижняя волосяная линия. Слева компактный
логотип, по центру навигация Exo 2 (Каталог, Доставка, Контакты), справа поиск, язык, вход и корзина.
Счётчик корзины в оранжевом кружке. ThemeToggle удаляется.

**Hero сайта** (по образцу брендборда): крупный заголовок «ІГРОВІ ДЕВАЙСИ ДЛЯ ТВОГО СЕТАПУ»
(второе слово-акцент оранжевым), подзаголовок-перечень «МИШКИ · КЛАВІАТУРИ · НАВУШНИКИ · АКСЕСУАРИ»
меткой, оранжевый CTA «Перейти до каталогу» со срезанными углами. Справа арт (HeroArt
перекрашен в монохром и оранжевое свечение) в HUD-рамке.

**Карточка товара**: `--surface`, радиус 12, фото на `--surface-2`, название Inter 600 в 2 строки,
цена Exo 2 700. Кнопка «В корзину» — `nb-accent`. Hover на десктопе: подъём на 2px, рамка светлее,
оранжевая полоса снизу. «Нет в наличии»: фото с пониженной насыщенностью, метка `--muted`.

**Чипы категорий и фильтров**: pill, активный = `--accent-soft` + оранжевая рамка.

**Навбар Mini App (TabBar)**: плавающий, `--surface` с opacity .92 + blur, радиус 16, рамка `--line`.
Активный таб: иконка и подпись оранжевые, сверху оранжевая полоска 2px со свечением.

**Поля ввода**: `--surface-2`, рамка 1px `--line`, радиус `--r`; фокус: рамка `--accent` + `--accent-soft` ring.

**Статус-чипы**: тёмный фон `color-mix(статус 16%, transparent)`, текст и точка цветом статуса.
Без чернильной рамки.

**Тосты, шторки, модалки**: `--surface`, рамка `--line-strong`, радиус 16 (верхние углы у шторки),
backdrop `rgba(0,0,0,.6)` + blur 6px.

**Карта НП (Leaflet)**: тайлы OSM остаются светлыми. На тёмную тему их не перекрашиваем (filter invert
ломает читаемость). Карту оформляем рамкой 1px и радиусом 12, пины и кластеры оранжевые.

**Чат**: мои сообщения — `--accent-soft` с оранжевой рамкой слева 2px; входящие — `--surface-2`.

## 8. Админка (v3)

Админка (`frontend-admin/`, русский интерфейс) переходит на ту же айдентику. Это рабочий
инструмент с плотными таблицами и канбаном, поэтому стиль тот же, а декора меньше. Этап 1
(фундамент: токены, оболочка, примитивы, вход, PWA, графики) готов. Экраны переводятся поверх него,
чек-лист и инвентаризация остатков v2 лежат в `.devdata/v3/admin/FOUNDATION.md`.

**Тема и токены** (`frontend-admin/app/globals.css`). Одна тёмная тема: светлая тема, переключатель
и `data-theme` удалены. Имена токенов админки сохранены (`--text`, `--line`, `--border-2`, `--r-sm…xl`,
`--shadow-1…3`, `--ring-accent`, `--c3` …), поменялись только значения. Общие с
Mini App и сайтом имена (`--bg`, `--surface*`, `--accent*`, `--st-*`, `--chamfer`,
`--ink/--muted`) имеют те же значения. Своё у админки:

| токен | значение | зачем |
|---|---|---|
| `--bg-2` | `#131315` | утопленные полосы: тело колонки канбана, шапка таблицы, футер модалки, трек сегментов |
| `--surface-hover` | `#262628` | hover строки/пункта на `--surface` |
| `--text` | `#F4F4F5` | основной текст (чистый белый `--ink` только для заголовков: длинные таблицы в #FFF «режут») |
| `--border-2` | `rgba(255,255,255,.12)` | рамка кнопок и hover полей |
| `--accent-soft-2` | `rgba(255,102,0,.22)` | кольцо фокуса `--ring-accent`, сильное выделение |
| `--danger-ink` | `#FCA5A5` | красный текст на тёмном |
| `--info` | `#60A5FA` | инфо-чипы («Сайт») |
| `--r-sm/md/lg/xl` | 4 / 6 / 12 / 16 | чипы / контролы / карточки / модалки и шторки |
| `--shadow-1/2/3` | мягкие | карточка / панель / всплывающее (меню, тост, модалка) |
| `--glow-sm` | `0 0 10px rgba(255,102,0,.55)` | свечение 2px-индикаторов |

**Типографика** (плотность). Inter (`--font-body`) для текста, таблиц, полей и значений в ячейках.
Exo 2 (`--font-display`) для заголовков страниц (`.page-title`, 800 КАПС), заголовков секций
(`.section-title`), больших чисел KPI (`.kpi-num`, 700 tabular), навигации, кнопок, бейджей, табов,
подписей полей (`.field-label`) и надзаголовков (`.eyebrow`). `font-black` не используется (у Exo 2
нет 900). Inter 800 тоже не используется.

**Оболочка.** Сайдбар `--surface` с волосяной линией справа. Сверху компактный векторный логотип и
«ADMIN»-eyebrow с оранжевым штрихом. Сайдбар сворачивается в рельс 76px с марком CS, состояние
хранится в `localStorage`. Пункт навигации: Exo 2 600, иконка `--text-faint`. Активный пункт:
оранжевые текст и иконка на `--accent-soft`, слева полоска 2px `--accent` со свечением, которая
переезжает между пунктами. Счётчики — `.count-badge` (оранжевый «Внимание», серый «Переводы»).
Топбар `rgba(14,14,16,.85)` + blur, на телефоне слева марк CS. Таб-бар телефона `--surface` .92 + blur.
Активный таб, как в Mini App, получает оранжевые иконку и подпись и полоску 2px сверху со свечением.

**Примитивы.** Классы (`.card`, `.panel`, `.elevated`, `.card-2`, `.glass`, `.nb-press`,
`.shimmer` …) сохранили имена, теперь это графит + 1px. Новые классы: `.card-hover`, `.accent-tint`,
`.nb-accent`, `.nb-chip(-active)`, `.chip-tint` (тонированный чип: `--chip` 16% + текст цветом),
`.count-badge`, `.eyebrow`, `.field-label`, `.page-title`, `.section-title`, `.kpi-num`,
`.data-table` (компактная таблица), `.chamfer`, `.hud-frame` (та же исправленная реализация, что во
фронте и на сайте: углы хоста срезаны под скобки). React-компоненты
`components/ui/*`:
- `Button`: варианты accent / surface / outline / ghost / danger, Exo 2 700 КАПС, проп `chamfer` для
  одной главной CTA;
- поля: h-10, фокус = оранжевая рамка + кольцо;
- `Toggle`: pill, во включённом состоянии оранжевый со свечением;
- `SegmentedControl`: активный сегмент на tint, без сплошной заливки;
- `Modal` / `Drawer`: `--surface`, рамка `--line-strong`, r 16, backdrop `black/60 + blur 6`;
- `Badge` / `StatusBadge`: тонированные pill-чипы, как статус-чипы Mini App;
- `EmptyState`: в HUD-рамке;
- тосты: `.elevated` + цветная полоска слева.

Логотип админки (`components/brand/Logo.tsx`) берёт геометрию из `@shop/shared`: `Wordmark`,
`LogoFull`, `LogoMark`. Вход (`components/auth/Login.tsx`) — полный логотип в карточке с
HUD-рамкой, «Войти» оранжевая со срезом.

**Акцент.** Сплошной оранжевый остаётся у главной кнопки экрана и счётчиков. Активные табы,
фильтры, выбранные строки и пункты меню получают `--accent-soft` + оранжевую рамку или текст.
Статусы (`--st-*`) показываются tint 16% + цветной текст или точка, без сплошных плашек под
тёмным текстом. Допустима полоса 2px цветом статуса сверху колонки канбана.

**Графики** (`components/metrics/metrics.css` + JS-зеркало `lib/metrics-format.ts`). Монохром и один
оранжевый: основная серия `#FF6600`, вторичная стальная `#7B93B8`, третья светло-серая `#D4D4D8`,
прошлый период `#8A8A93` пунктиром. Сетка `rgba(255,255,255,.06)`, оси `rgba(255,255,255,.4)`.
Тепловая карта и воронка — последовательная оранжевая шкала от тёмного к яркому («больше» светится).
Статусные графики берут `--st-*`. Тултип — графитовая карточка (`ChartTooltip`, `TipBox`) с
заголовком Exo 2 КАПС. Палитру проверили валидатором dataviz на `#1A1A1A`: соседние серии
различимы и при дальтонизме (ΔE ≥ 19), и при нормальном зрении (ΔE ≥ 22). Нейтральные серии
сознательно не проходят «порог насыщенности», поэтому у графиков с двумя и более сериями всегда
есть легенда и второе кодирование (пунктир, бары против линий). Одна серия — один цвет: столбики
не красим каждый своим цветом.

**PWA.** Иконки — марк CS. Генератор `frontend-admin/scripts/build-pwa-icons.mjs` (Playwright, как
`render_brand.mjs`) делает:
- any 192/512 — скруглённая плитка;
- maskable 192/512 — арт на 74% на графите, чтобы скобки влезли в круг 80%;
- apple 180 — full bleed;
- badge 96 — белый силуэт.

Также `app/icon.svg` = `docs/brand/v3/mark.svg`. Манифест: «ChiSetup Admin», theme и background
`#0E0E10`. `offline.html` — автономная HUD-карточка.
