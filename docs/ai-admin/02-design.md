# 02. Дизайн: встроенный ИИ в новой админке

Роль: продуктовый дизайнер. Основа: `01-business.md`, `00-inventory.md`, дизайн-система `admin-redesign` (shell-system, токены макетов). Макеты: [`mockups/index.html`](mockups/index.html) (статичные HTML, стили из admin-redesign, телефон 375 и десктоп 1280, без маскота). Цифры и имена в макетах придуманы.

## 0. Главные решения

1. **Основной путь = одна акцентная кнопка в контексте** («Заполнить с ИИ», «Прочитать с ИИ», «Перевести с ИИ») с иконкой ✦. Под ней строка «≈ 0,2 ₴ · около минуты». Ручной путь = серая ссылка «Через ChatGPT вручную» рядом, плюс «Показать промпт» в «⋯».
2. **Ручной путь выходит вперёд (становится акцентным) только когда ИИ недоступен**: выключен, лимит, ключ, нет связи, 3 ошибки подряд, результат «Пусто». Серой мёртвой кнопки без причины нет.
3. **Один паттерн на все функции**: вход → (подтверждение, только если нужно) → фон → «Готово, ждёт проверки» → ревью → применить. Один движок, один журнал, одно ревью.
4. **Один глобальный индикатор**: чип ✦ в шапке (число идущих задач; без пульса = только ждёт проверки; жёлтый = проблема; серый «выкл»). Тап открывает шторку (телефон) или поповер (ПК). На телефоне чип встаёт в пустое правое место шапки, нижняя панель не меняется.
5. **Центр задач = журнал**: раздел «Каталог → ИИ-задачи» (бейдж = ждёт проверки). Вкладка «Все» это журнал, остальные вкладки это очередь.
6. **Деньги видит только владелец.** Обычный админ видит время и статус «можно запускать / лимит исчерпан».
7. **Защита работы людей в ревью**: поля сгруппированы по риску, а не по алфавиту. Пусто→заполнено (включено), заменит значение (выключено), «правил человек» (заблокировано), сомнительно (выключено, с причиной).

## 1. Единый паттерн — [01-pattern.html](mockups/01-pattern.html)

### 1.1. Кнопка-вход
| Где | Вид |
|---|---|
| Футер окна на телефоне | Во всю ширину, высота 48, под ней подпись-оценка, ниже ссылка «Через ChatGPT вручную» (44 px высота касания) |
| Футер окна на ПК | Кнопка 220×44, справа от неё оценка, у правого края ссылка ручного пути |
| Панель выбора в списке | `Заполнить с ИИ (40)` accent + «⋯» (ручные пачки по 4/8, показать промпт) |
| Панель над списком («Переводы») | Кнопка справа, объём = то, что показывает фильтр списка |

Подпись: владелец «≈ 0,2 ₴ · около минуты», админ «около минуты». Для пачки диапазон «8–12 ₴».

### 1.2. Состояния входа (6)
Готово · уже идёт (показываем «Запустила Анна, 1 мин назад» и открываем ход вместо второго платного запуска) · лимит исчерпан (ручной путь accent) · ИИ выключен · нет связи · поиск недоступен (3 кнопки: подождать / без поиска с пометкой / вручную).

### 1.3. Подтверждение с оценкой
Показывается **только** если пакет > 5 товаров, оценка > 2 ₴ или «тщательный» режим (пороги из настроек). Один товар и накладная идут сразу. Содержимое (владелец): стоимость и диапазон, время, «лимит на сегодня: хватит / осталось N ₴», выбор «быстро/обычно/тщательно», «можно закрыть экран». Админ: время и «хватит / не хватит», без сумм. На телефоне шторка, на ПК окно 520.

### 1.4. Прогресс
Шаги простыми словами («Ищу в интернете», «Читаю страницы», «Собираю ответ»), таймер, живые факты («3 поиска, найдено 4 страницы»). Две кнопки: «Закрыть — продолжу в фоне» и «Остановить». Через 3 минуты подсказка «Это дольше обычного». Задача живёт в БД, закрытие окна её не трогает; у товара/строки метка «ИИ работает».

### 1.5. Результат и ревью
Готовая задача: тост «Lamzu Maya X 8K готова · Открыть» (если админ в другом экране) + чип ✦. Ревью: плашка происхождения («Заполнено встроенным ИИ · задача № 412 · 5 источников»), счётчик «Принять 9 из 14», группы полей (см. п. 0.7), у каждого поля уверенность (≥80 зелёный, <40 красный), ссылка на источник, пометка причины. Красное нельзя применить, можно «оставить пустым». Футер: «Применить выбранное (9)», «⋯» (повторить тщательнее с ценой, вручную, показать ответ, показать промпт), «Отклонить», галочка «Сразу выложить на витрину» (по умолчанию выкл).

### 1.6. Статусы (всегда один из пяти)
Готово · Пусто · Ошибка · Отменена · Прервана. Для каждого видна причина одним предложением и следующий шаг. «Показать ответ» доступен при «Ответ не читается».

### 1.7. Переход в ручной путь без потерь
Ссылка «Через ChatGPT вручную» открывает в том же окне три шага (Промпт · Ответ · Проверка). Промпт уже собран из выбранных параметров (режим, фото, подсказки). Вверху баннер «Вернуться к встроенному ИИ ✦». Конец один: тот же ревью. Если админ уже снимал галочки или правил поля, а потом вставил новый ответ или повторил с ИИ, спрашиваем «Сохранить ваши правки поверх нового ответа?» (по умолчанию да). В журнал пишется путь: «встроенный» / «вручную».

## 2. Функции MVP

### 2.1. Карточка одного товара и дозаполнение — [02-card-modal.html](mockups/02-card-modal.html)
Одно окно на три входа (после создания товара, строка списка, товар поставки).
1. **Старт**: мини-карточка товара (заполнено 62 %, пусто 8 из 21), «Как искать» (быстро / обычно / тщательно), фото (добавить 3, только если фото нет), число используемых подсказок. Кнопка «Заполнить с ИИ».
2. **Работает**: шаги, таймер, «Закрыть — продолжу в фоне».
3. **Ревью**: п. 1.5. Для дозаполнения то же окно: группа «Заменит значение» выключена, группа «Правил человек» заблокирована (значок замка, кто и когда правил).
4. **Вручную**: п. 1.7.
5. **Лимит**: баннер, «Скопировать промпт» accent, ИИ-кнопка серая с причиной.
6. **Конфликт**: «Пока работал ИИ, карточку правил Иван» — изменённые после старта поля заблокированы, остальные применимы.
ПК: окно 620 на старте, на ревью 980 в два столбца (поля слева; источники и выбор фото справа); кнопки в футере окна, не плавают над сеткой.

### 2.2. Пачка — [03-batch.html](mockups/03-batch.html)
Выбор строк → «Заполнить с ИИ (N)» → подтверждение с оценкой → полоса над списком «Пакет идёт: 12 из 40 · остановить · потрачено 2,4 ₴» (суммы только владельцу) → готовое появляется во вкладке «Проверить» по мере готовности. Лимит посреди пакета: **пауза**, не провал («Готово 18 из 40. Остальные 22 ждут. Завтра продолжим сами или оформите вручную»). Итог: «32 готово · 5 пусто · 3 ошибки», кнопки «Повторить неудачные (8)» и «Принять уверенные (21)». На ПК таблица, строка выбора внизу списка, полоса пакета над таблицей.

### 2.3. ИИ-поставка — [04-supply.html](mockups/04-supply.html)
Лента из 4 шагов: Файлы → Чтение → Строки → Форма поставки. Загрузка скринов/PDF («файлы не хранятся»), поставщик, «Прочитать с ИИ ≈ 0,1 ₴ · около 10 секунд». Результат: плашка «Прочитано 6 из 6, сумма сошлась, повторы на стыках убраны», строки с пометкой сопоставления (память поставщика / новый товар? / нет в каталоге). ПК: справа исходные скрины для сверки. Этап 2: сопоставление встроенным ИИ и плашка «Оформить карточки с ИИ для 3 новых товаров». Нужен вход с картинками в бэкенде; пока его нет, кнопка заменена ручным путём.

### 2.4. Переводы — [05-translations.html](mockups/05-translations.html)
Кнопка «Перевести с ИИ (84)» над списком, объём = фильтр списка. Подпись «3 части по 60 строк · ≈ 0,3 ₴ · около 2 минут». Прогресс по частям. Проверка: сводка «79 новых · 5 заменит · 0 ошибок», предупреждение о 5 переводах, сделанных вручную (не заменяются, пока не включены по одной). «Записать 79 переводов» кладёт их в «Проверить ИИ». Автоперевод при правке оригинала — этап 2, настройка выключена.

## 3. Центр ИИ-задач — [06-task-center.html](mockups/06-task-center.html)
- Вкладки: Все (журнал) · Идут · Проверить · Проблемы. На ПК ещё фильтры: функция, админ, период, путь.
- Строка: значок функции, объект, «функция · шаг · кто», статус-тег, время, стоимость (только владелец).
- Деталь (шторка / панель справа): запустила, длительность, стоимость, ход работы, исход, «Открыть проверку», «Повторить», «Отклонить». «Промпт и ответ» только владельцу, хранятся 60 дней.
- Админ видит задачи по доступным объектам без сумм и промптов, отменяет свои. Владелец отменяет любые и видит «Остановить всё».

## 4. Настройки → ИИ — [07-settings.html](mockups/07-settings.html)
Страница «Настройки», группа «ИИ», только владелец. Блоки: Состояние (статус модели, ключа и поиска; выключатель; «Остановить всё немедленно»), Функции (карточки, переводы, поставка; этап 2 выключены), Лимиты (месяц, день, на админа, пакет, порог предупреждения; что делать при исчерпании: остановить и ручной / до завтра / спросить), Качество (быстро/обычно/тщательно по функциям; что делать при недоступном поиске), Поиск (SearXNG и Serper со статусом, расходом и «Проверить поиск»), Что видит админ (показывать их расход, срок хранения), Уведомления, Показ (курс, трудоёмкость), Модель и ключи (только чтение: меняются в .env). Один «Сохранить» липнет снизу со сводкой изменений; у поля «к умолчанию».

## 5. Метрики — [08-metrics.html](mockups/08-metrics.html)
Вкладка «ИИ» в «Метриках», выбор периода как у остальных вкладок. Главные 8 чисел: потрачено за месяц и % лимита, прогноз (подпись «оценка»), ₴ на результат, принято без правок, ждёт проверки, проблемы, поиск, сэкономлено (подпись «оценка, по константам»). Дальше график по дням (ошибки красным), срезы: функции, результаты, провайдеры (токены, SearXNG/Serper, страницы), админы (только владельцу), топ исправляемых полей, «зря потрачено» со ссылкой в журнал. Виджет на дашборд: владелец видит расход и ждущих проверки, админ только «можно запускать» и число ждущих.

## 6. Состояния — [09-states.html](mockups/09-states.html)
Пусто, загрузка (скелет), ошибка «Ответ не читается», строки «пауза / отменена / прервана / ошибка», офлайн, поиск недоступен, двойной запуск, ИИ выключен, ключ не принят (владельцу), лимит 100 % (владельцу), лимит дня на ПК. Телефон 375 и ПК 1280; при реализации прогнать 320…2560 по `shop-ui-qa`.

## 7. Тексты (русский, коротко)
Кнопки: «Заполнить с ИИ», «Прочитать с ИИ», «Перевести с ИИ», «Через ChatGPT вручную», «Закрыть — продолжу в фоне», «Остановить», «Применить выбранное (9)», «Повторить», «Повторить тщательнее», «Повторить неудачные (8)», «Показать ответ», «Вернуться к встроенному ИИ». Статусы: Идёт, Проверить, Применено, Пусто, Ошибка, Отменена, Прервана, Пауза. Ошибки: «Ответ не читается», «Сервис ИИ недоступен», «Поиск недоступен», «Лимит ИИ на сегодня исчерпан», «ИИ отключён владельцем», «Прервана перезапуском сервера». Слов «effort», «токены», «ходы» админу не показываем (токены только в метриках владельца).

## 8. Доступность и телефон
Высота касания ≥ 44 px, шторки вместо окон на телефоне, чип ✦ не единственный индикатор (есть текст в шторке и тост), анимация пульса выключается при `prefers-reduced-motion`, цвета статусов всегда с текстом, не только цветом. Совместимость iOS 15.4+: без lookbehind и новых CSS-функций.

## 9. Что решить владельцу по дизайну
1. Название раздела: «ИИ-задачи» (предложено) или «ИИ».
2. Показывать ли админам их расход (макет: нет).
3. Порог подтверждения пакета (макет: > 5 товаров или > 2 ₴).
4. Нужен ли push «готово» группой (этап 2) или хватает чипа и тоста.
