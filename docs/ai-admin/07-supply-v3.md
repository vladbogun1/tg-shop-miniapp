# «Поставка с ИИ» v3: накладная без потерь, варианты, экран «одним потоком»

Статус: ветка `feat/supply-v3` (09.11.2026), не на проде, без миграций (всё в JSON `supply_drafts.state`).
Повод — черновики №3/№9/№10 на проде: ИИ терял строки на стыке скринов (−2 Sora в №9), путал тубус/конверт,
а приём блокировали «несколько строк без вариантов»; экран был двумя таблицами («Строки» → «Новые товары»).

## Чтение накладной (бэкенд, `procurement`)

- Повторы на стыке скринов убираются **по итогу документа** (`SupplySeams`, `SupplySubsets`): одинаковая строка
  в конце скрина N и начале N+1 выкидывается, только если без неё сумма сходится с итогом. Иначе — оставляем.
- Строки не сходятся с итогом → автоматическая перепроверка той же моделью MiniMax в тщательном режиме
  (`SupplyVerify`, задача VERIFY, до 2 попыток), берётся чтение, которое ближе к итогу (`SupplyDraftReading`).
- Кнопка «Перечитать» (`POST /api/admin/supply-drafts/{id}/reread`): ИИ читает заново, в черновик **добавляются
  только недостающие** строки (R1…), решения админа не трогаются.
- Ручные строки M1… (`DraftSaveRequest.addLines`) и «Убрать из документа» (`removeLines`).
- `DraftDto.sum` — сколько раз перечитывали и какие повторы убраны; сверку суммы считает фронт (`draftSum`, допуск 1 %).

## Варианты вместо блокировки

- Правило владельца: **цвет — отдельный товар; основа (Soft/Xsoft) и упаковка (тубус/обычная) — варианты** одного
  товара. Промпт сопоставления `supply-match-3`, промпт чтения `supply-3` (заметки строго по-русски).
- Строки одного нового товара без варианта больше не блокируют приём: `SupplyVariants` (Java) = `lineVariants` (TS)
  даёт каждой строке слова, которыми она отличается от остальных («Xsoft gift tube packaging»); одна и та же позиция
  дважды — без варианта, складывается. Админ видит подстановку в подсказке поля «Вариант».
- Карточка ИИ назвала два новых товара одинаково → это один товар с вариантами + предупреждение админу
  («Отделить в свой товар», если ошибся).

## Экран проверки черновика (`frontend-admin/features/supply/ui/drafts`)

Одна лента вместо двух таблиц: сверху сверка суммы («Сходится с заказом · ¥…» / сколько не хватает и что делать),
«Готово N из M» с кнопками-прыжками к нерешённому, шапка поставки, затем позиции накладной по порядку — каждая
карточкой: «Наш товар» (что подобрал ИИ, «Другой товар») или «Новый товар» (название, категория, цена, варианты
строк, карточка ИИ — всё в одном месте). Внизу липкая «Принять» (на телефоне в одну строку).
