# wild-1-royale — «Гарбузовий Рояль»

Статус: active. Визуал розыгрыша для Хеллоуин-стрима ChiSetup: открыть `?visual=wild-1-royale`.

## Концепты (оценки 1–5: вау / понятность за 3 с / честность / реализуемость за часы)

1. **Гарбузовий Рояль (ВЫБРАН)** — каждый участник это точка на острове-карте; по команде зона шторма
   сжимается в 3 этапа, точки вне зоны краснеют, бегут и гибнут, в килфиде мелькают имена чата,
   в финале 3 выживших дуэлятся при зуме. Победитель задан заранее: зона строится вокруг его точки. 5 / 5 / 5 / 4 = 19.
2. **Бос-файт «Гарбузоголовий»** — босс с HP = всем билетам, участники это стрелки-«хитбары», последний удар
   у победителя. Понятно, но удар «по сценарию» читается как постановка, много спрайтов. 4 / 5 / 3 / 2 = 14.
3. **Бан-хаммер** — бегущий чат из имён участников, модератор-молот банит всех подряд, остаётся один.
   Мета-шутка про Twitch, но визуально бедно и похоже на список. 3 / 5 / 5 / 5 = 18 (по вау слабее).
4. **Мега-гарбуз распадается** — все участники собираются в одно гигантское существо, оно рассыпается
   на кластеры, пока не остаётся один. Красиво, но «кто остался» не читается без подсказки. 4 / 3 / 4 / 3 = 14.
5. **Зомбі-апокаліпсис** — один «нульовий пацієнт» заражает толпу, последний здоровый выигрывает.
   Понятно, но победитель заранее виден как «последний, до кого не добежали», а заражение выглядит однообразно. 4 / 4 / 3 / 3 = 14.
6. **Лаг-стрим / глитч-вылет** — «стрим ломается», мир рассыпается на пиксели, имена отваливаются, уцелевает одно.
   Смешно один раз, но пугает зрителей и конфликтует с OBS-камерой. 3 / 3 / 4 / 4 = 14.

Выбран №1: единственный, где у всех на экране «своя точка» (чат орёт «я жив!»), геймерам понятно с первого кадра,
честность встроена в механику (зона физически строится вокруг заданного победителя), и это можно сделать за часы.

## Как устроено

- Арт (версия «спокойная», 2026-10-26) — сдержанный пиксель-арт: почти чёрный #0E0E10, графит и холодные тени, оранжевый #FF6600 только точечно, зелёный/фиолет лишь как редкие акценты. webp в `assets/` (~0,4 МБ):
  `terrain` (карта 1920×1080, Codex/gpt-image), `land.png` (маска суши, получена из terrain), `lm-*` (6 локаций, меньше и проще), `fighters` (бойцы с тыквой-головой, 2–3 тона, 4 фракции = цвет шарфа × idle/бег/бег/выстрел, строка 4 с короной — победитель), `atlas`+`atlas.json` (рисуется кодом build.py: вспышки, попадания, пули, дымки, жетоны, проп, парашют; реквизит, сундук и летучие мыши — приглушённые копии старых), `arena`, `storm` (тёмный тайл шума).
  Рамка и лента победителя — CSS (пиксельные ступенчатые рамки), картинок `frame`/`ribbon` больше нет. Старая яркая версия: коммит 20817c7.
- Участники: топ по билетам — спрайты с именем/аватаром (до 64), остальные — жетоны-маркеры; 2000 остаются толпой. Победитель и два «двойника» всегда спрайты.
- Ролл (~34 с): высадка на парашютах → зона 1 → 2 → 3 → арена → финал. Выбывание в основном из перестрелок
  (снаряды, вспышки, отбрасывание, дуэли через карту, килфид «X вибив Y») плюс шторм. Каждая надпись держится ≥ 2,5 с.
- Честность: победитель задан заранее (`killDot` его не убивает), бои — хореография, он выигрывает все свои бои; финал: дуэль двойников, 1 HP, победа.
- Приз: `setPrize(prize|null)` (хост вызывает сам) и `info.prize` в `roll` — плашка «Розігруємо: <назва>» вверху и «Виграв: <назва>» на карточке победителя; null скрывает.
- `ctx.privacy.avatars`, `reducedMotion`, resize учтены. Файлы: `index.js`, `style.css`, `assets/`.
