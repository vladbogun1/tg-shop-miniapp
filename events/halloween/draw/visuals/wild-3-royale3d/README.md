# wild-3-royale3d — королівська битва 2.0 (three.js)

Статус: active (на демо, у прод не виходило).

Тривимірний острів-цвинтар на three.js (копія в `vendor/`, без CDN). Учасники висаджуються метеорами,
шторм стискає зону, камера перелітає між поєдинками героїв, у фіналі — арена, леттербокс і слоумо.
Переможець визначений заздалегідь (контракт `VISUAL-CONTRACT.md`) і ніколи не програє.

- `index.js` — mount/roll/reset, рендер, пост-обробка (bloom + віньєтка/радіальний блюр), камера, HUD, підписи.
- `director.js` — сценарій розіграшу: каст (до 16 героїв, 5 фіналістів), бої, банери, кадри камери, слоумо, шторм.
- `fighter.js` — низькополігональний гарбуз-боєць, пози і удари.
- `crowd.js` — решта учасників інстансами (до 2000), смерті натовпу.
- `world.js` — острів, локації, арена, шторм. `fx.js` — частинки, сліди зброї, кільця.

Тривалість: ~70 с сценарного часу, ~75–80 с реального зі слоумо. Якість знижується сама, якщо fps падає
(тіні → bloom). Налагодження: `root._r3()` — фаза, час, кадр.
