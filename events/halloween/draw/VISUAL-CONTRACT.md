# Экран розыгрыша — контракт визуала

Страница `events/halloween/draw/index.html` — экран для стрима Максима (OBS, 1920×1080, тёмный фон).
Хост (`host.js`) грузит участников, держит панель управления и спрашивает сервер, кто выиграл.
**Визуал только показывает.** Победителя выбирает сервер ДО анимации, визуал обязан красиво
и честно приехать именно к нему.

## Как запустить локально

```bash
cd events/halloween/draw
npx --yes http-server -p 4810 -c-1 .
```

`http://localhost:4810/?mock=180&visual=<имя>`: `mock=N` — N фейковых участников (имена uk/ru/en,
часть с аватарками, разное число билетов). Без `mock` хост ходит в `/hw/api/admin/...`.
Клавиши хоста: `R` — ролл, `H` — спрятать/показать панель (на стриме панель прячут), `M` — звук.

## Модуль визуала

Папка `visuals/<имя>/`, в ней `index.js` (ES module) и всё своё (css, картинки, звуки, vendored-библиотеки).
Ничего снаружи своей папки не менять (`registry.js` тоже не трогать, его правит хост). Любая папка открывается как `?visual=<имя папки>`. Сборщиков нет: чистый
ES module в браузере. CDN нельзя, библиотеку кладём копией в свою папку (`vendor/`).

```js
export const meta = { id: "cauldron", title: "Котёл ведьмы", author: "agent" };

/** root — пустой <div> на весь экран; ctx — см. ниже. Вернуть объект-контроллер. */
export function mount(root, ctx) {
  return {
    /** Список поменялся: пришли новые участники, кто-то выиграл и выбыл. Анимировать появление. */
    setParticipants(list) {},
    /** Главное. Анимация ролла, которая останавливается на winner. Resolve, когда победитель показан. */
    async roll(winner, info) {},
    /** Хост просит вернуть «живое» ожидание перед следующим роллом (снять показ победителя). */
    reset() {},
    destroy() {},
  };
}
```

### Участник

```ts
type Participant = {
  id: string;            // стабильный, непрозрачный
  name: string;          // «Олег К.» — уже обрезано и безопасно для стрима
  handle: string | null; // «@ole***» — уже замаскировано, может быть null
  avatar: string | null; // URL картинки или null (рисуй свою заглушку: тыква/призрак с инициалом)
  tickets: number;       // 1..N, шанс пропорционален билетам
  pumpkins: number;      // сколько тыкв собрал (0..∞)
  orders: number;        // сколько заказов за неделю
  via: ("pumpkins" | "orders")[]; // за что попал в розыгрыш
  won: boolean;          // уже выиграл в одном из прошлых раундов (не участвует, можно показать иначе)
};
```

`info` в `roll`: `{ round: 1..5, totalRounds: 5, totalTickets, seedHash }`.

### ctx

- `ctx.sound(name)` — короткие звуки хоста (`tick`, `whoosh`, `boom`, `win`, `drum`). Можно и свои.
- `ctx.reducedMotion` — boolean. Даже так ролл должен быть зрелищным, просто без вспышек на весь экран.
- `ctx.privacy` — `{ avatars: boolean }`. Если `false`, аватарки не показывать.
- `ctx.size` — `{ w, h }` экрана; ещё ловить `resize`.

## Требования

1. **Не список.** До ролла участники «живут» на экране, их видно, и это красиво на стриме.
   Чем больше билетов, тем заметнее участник (размер, свечение), но и с 1 билетом его видно.
2. Должно держать от 5 до 2000 участников. На 2000 не показывать все имена: кучи, рои, облака.
3. Ролл длится 8–15 с, с нарастанием напряжения, ложными остановками и звуком. Финал: имя победителя
   крупно, читается с телефона, который смотрит стрим.
4. Иначе показать, что победитель выбран заранее, нельзя: никаких «выиграл один, показали другого».
   Если в визуале есть физика, то она «подыгрывает» к заданному победителю.
5. 60 fps на обычном ноутбуке в Chrome (OBS Browser Source). Canvas/WebGL/CSS — на выбор.
6. Стиль — Хеллоуин в бренде ChiSetup: тёмный `#0E0E10`, тыквенно-оранжевый `#FF6600`, ядовито-зелёный
   `#7CFF4F` / фиолетовый `#8A3FFC` как вторые акценты, шрифт `"Exo 2"` (уже подключён в host.css, просто `font-family: "Exo 2"`), пиксельный маскот
   (качок в майке «21») — спрайты лежат в `assets/sprites/` (+ `manifest.json` с размерами и числом кадров; пиксель-арт: целые масштабы, `image-rendering: pixelated`). Путь из модуля: `new URL("../../assets/sprites/hero_wave.png", import.meta.url)`. Использовать не обязательно.
7. Тексты на экране по-украински (стрим украинский): «Учасники», «Квитки», «Переможець», «Раунд 2 з 5».
