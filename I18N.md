# I18N — интерфейс на трёх языках

Ветка: `i18n`. Третий заход после `AUDIT-FIXES.md` и `UI-FIXES.md`.

**Что делаем:** магазин говорит на украинском, русском и английском. **Контент
(названия и описания товаров) в этот заход НЕ трогаем** — он остаётся русским и
переводится отдельной попыткой (владелец не хочет платить за модель; вариант —
разовый прогон пачками или лёгкая модель на сервере).

**Что НЕ делаем:** админка остаётся русской. Один продавец, один язык; перевод
815 строк бэк-офиса не окупается.

---

## Почему приоритеты такие

Язык покупателя Telegram сообщает сам, и магазин его уже собирал (`users.language_code`).
Живые данные прода на момент начала работ:

| язык | пользователей | заказов |
|---|---|---|
| ru | 1377 (57%) | 479 |
| uk | 695 (29%) | 227 |
| не указан | 257 (11%) | 300 |
| en | 83 (3%) | 22 |

Украинский — треть аудитории, не «на будущее». Английский маленький, но ненулевой.

**Запасной язык — украинский** (решение владельца): магазин украинский, и если
Telegram про человека ничего не сказал, он увидит украинский.

## 1. Фундамент

- [x] `frontend/i18n/locales.ts` — языки, их самоназвания, BCP-47 теги
      (`en-GB`, а не `en-US`: день-первым и 24 часа ближе к тому, что ожидает
      покупатель в Украине).
- [x] `frontend/i18n/types.ts` — форма словаря и поиск фразы. Ключи **плоские
      и через точку**, а не вложенные объекты: так TypeScript ловит пропущенный
      или опечатанный ключ в другом языке на компиляции.
- [x] Множественные числа — через `Intl.PluralRules`, без своей арифметики.
      Самописный русский `plural()` из корзины удалён.
- [x] `frontend/i18n/context.tsx` — определение языка: выбор человека (на
      устройстве) → `language_code` из Telegram → украинский. Никакой модалки
      «выберите язык» на первом запуске.
- [x] Первый рендер и на сервере, и на клиенте одинаковый, настоящий язык
      применяется в layout-эффекте — гидрация сходится, вспышки чужого языка нет.
- [x] `frontend/i18n/active.ts` + обёртки `lib/format.ts` и `lib/money.ts` —
      даты и суммы форматируются по текущему языку. Раньше при любом интерфейсе
      они были русскими (`ru-RU` был зашит).
- [x] Смена языка перемонтирует дерево: цены и даты форматируются обычными
      функциями, и экран, где нет ни одной переводимой строки, иначе остался бы
      со старым форматированием.

## 2. Вынос строк

- [x] 209 ключей, 25 файлов клиента. Русский словарь `frontend/i18n/ru.ts` —
      единственный, который правят руками.
- [x] Причины отмены заказа: покупатель видит перевод, **продавцу уходит русский
      текст** — доска заказов остаётся одноязычной.
- [x] Вкладки на карте отделений были украинскими посреди русского интерфейса —
      теперь следуют выбранному языку, как и всё остальное.

## 3. Украинский и английский

- [x] `uk.ts` и `en.ts` — перевод с русского, те же 209 ключей в том же порядке.
- [x] Английский объявляет ровно две формы множественного числа, украинский три:
      тип требует одинаковые КЛЮЧИ, но не одинаковые формы.
- [x] Переключатель: компактная кнопка в шапке каталога рядом с темой + строка
      сегментов в аккаунте.
- [x] **Никаких флагов** — флаг это страна, а не язык. Только буквы: UA · RU · EN.
- [x] Каждый язык подписан на самом себе («Українська», а не «украинский»): если
      приложение открылось на чужом языке, список на этом же языке не поможет.

## 4. Бот на языке покупателя

- [x] `users.locale` (V17) — язык, выбранный руками. Отдельно от
      `language_code`, который Telegram перезаписывает при каждом входе.
- [x] `POST /api/me/locale` — приложение сообщает выбор серверу.
- [x] `backend/.../i18n/Messages.java` + `i18n/messages_{ru,uk,en}.properties` —
      тексты, которые бот пишет ПОКУПАТЕЛЮ: статусы, подарок, скидка, изменение
      состава, новое сообщение в чате, кнопка «открыть переписку».
- [x] Карточки в канал продавца, список отгрузки и админские уведомления
      остаются русскими литералами в коде — сознательно.
- [x] Причина отклонения подставляется как её написал админ: это свободный текст
      живого человека, машинно ломать его хуже, чем оставить.

## Чего этот заход НЕ закрывает

- Контент: названия, описания, варианты, теги, названия способов оплаты. Всё это
  пока показывается по-русски на любом языке интерфейса.
- Адреса отделений Новой Почты приходят из их API украинскими — так и остаются
  (адрес есть адрес).
- Реквизиты: номер карты, IBAN, имя получателя — юридические данные, не переводятся.
